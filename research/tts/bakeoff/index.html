Method
  • load: fresh python process per engine/voice; load_ms = process start (imports included) → model ready. Weights were already on disk and mostly in the OS file cache (not a cold-boot disk read).
  • synth: perf_counter around the engine call per sentence, sentences a→g in order in the same process; first sentence includes any first-call warm-up.
  • ttfa: first_chunk_ms if the engine streams (Piper: per sentence; Pocket: ~80 ms frames; XTTS: inference_stream 2nd pass; EMA/Antalia/Seslen: per sentence/clause; mlx stream=True), else synth_ms
  • rss: /usr/bin/time -l 'maximum resident set size' and 'peak memory footprint' for the whole process (MPS/Metal allocations show up in footprint, not RSS)
  • wer: whisper-cli 1.x, ggml-large-v3-turbo-q8_0, -l tr; digits → Turkish words on both sides, Turkish lowercase (I→ı, İ→i), suffix apostrophes dropped; word-level Levenshtein / reference words, weighted over the 7 sentences
  • numbers_ok: sentence c heard as containing 'seksen', 'yirmisi', 'otuzu' (whisper may write digits; they are spelled out first)
  • loudness: listening copies: ffmpeg loudnorm I=-16:TP=-1.5:LRA=11 (single pass) → mp3 VBR q2
  • flags: silencedetect -40 dB/0.25 s on raw wav: lead >0.5 s, trail >1 s, inner gap >0.8 s; syllable rate (vowels of the written text with numbers spelled / speech span) >8.5 or <3 syl/s; peak ≥ 0.999 (clipping)
  • english_ok: count of English tech words heard as such: d → pull, request, deploy; e → build, ios (5 total)

Failures

  • zonos3-native-clone (first attempts): 
    POST /v2/generate → HTTP 400 {"detail":"reference-mode cloning of audio requires zac-encoder.gguf and ssl-teacher.gguf; supply --zac-encoder and --ssl-teacher"}. Resolved: request speaker_mode "embedding" (the downloaded spk-encoder.gguf path). The first harness version also left 2 orphaned zonos3-server processes (SIGTERM hit /usr/bin/time, not the server); they were killed (pkill) and the script now signals the server PID directly.
  • mlx-moss-nano-clone: 
    Ran without exceptions but output is unusable for Turkish: read-back WER 94.5% (e.g. sentence a heard as 'Tanrım. Tanrım. …', sentence f = 9.5 s of mostly silence heard as 'Altyazı M.K.'). Kept in the tables as measured.
  • chatterbox-default: 
    Ran, but sentence d hallucinated ~5 s of extra babble after the text (WER 143%), f read as 'Dur duruldu'; clipping on d and g. Matches upstream issue #97 (short/hallucinated segments).
  • pocket (MPS): 
    Not retried: reels-lab pocket.py documents an MPS abort ('command encoder is already encoding'); all Pocket runs are CPU.

Skipped candidates

  • Cactus Compute — Not a TTS runtime: no TTS model in the Cactus-Compute HF org and no Turkish speech (see research/tts/landscape.md). Nothing to benchmark.
  • Higgs Audio v3 4B (bosonai/higgs-audio-v3-tts-4b) — 9.3 GB download (> 3 GB budget) and non-commercial license.
  • Trendyol-TTS 2.38B (VoxCPM2 Turkish fine-tune) — 5.1 GB torch repo / 9.3 GB MLX port (emrekoc/trendyol-tts-mlx) > 3 GB budget; VoxCPM2-4bit (2.2 GB) was measured instead as the closest proxy.
  • VoxCPM2 Turkish LoRA (mramazan/voxcpm2-turkish-tts-lora) — Needs the full-precision torch VoxCPM2 base; mlx-audio's 4-bit MLX model does not load LoRA adapters [INFERENCE from mlx-audio voxcpm2 code: no LoRA path].
  • MOSS-TTS 8B — Size far over the 3 GB budget.
  • TheStageAI/pocket-tts-100m-tr (Core ML / ANE build) — 151 MB, but its engines.zip is QLPA-encrypted and only runs inside the paid TheStage Apple SDK (model card) — no open runtime.
  • FreyaTTS — HF repo freya-tts/FreyaTTS not accessible (API 401: private or nonexistent).
  • Ahenk (teacher, 2B + LoRA) — GPU teacher of Ahenk Cep; VoxCPM2-class size (> 3 GB) — Ahenk Cep (the distilled 34 MB student) was measured instead.
  • Antalia-2 Mini / Ahenk Cep ONNX graphs — Measured through their PyTorch packages only; the ONNX graphs need the JS/Rust bookkeeping ported (only EMA Lightning got an ONNX run here, via the reference numpy pipeline). [INFERENCE] ONNX timing ~ EMA-ONNX class.
  • Supertonic 3 via sherpa-onnx Rust crate (cargo project) — Not built: the sherpa-onnx 1.13.8 Python wheel (same C++ core as the pinned crate) was measured instead.
